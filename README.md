## 常见问题

**优惠码能叠加吗？**
一单通常只能填一个码。首单立减券是系统自动扣的，能不能和码同时生效，结算页的金额会直接告诉你，能叠就叠上了，叠不上数字不会动。

**`PCALL` 一直有效吗？**
第三方把它标为长期有效的全场 9.5 折码，但没有官方截止日期可查。用之前先在结算页试，抵扣成功再用。

**买错了能退吗？**
虚拟商品一经交付原则上不退。版本、平台、设备数这三项必须在下单前确认好。

**买断版是永久免费更新吗？**
不一定。买断指的是使用授权，更新政策各家不同，商品页会写明含不含后续版本更新，看清楚再买。

**Mac 和 Windows 都要用怎么办？**
看有没有多设备版。没有的话就得买两份单机授权，别指望一个码两台机器都能激活。
